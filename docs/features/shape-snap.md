# Shape snap

## Purpose
Circling things is the main use. With the Pen, holding still at the end of a rough closed loop turns it into a clean ellipse or rectangle, the same hold gesture the highlighter already uses for straight lines. Freehand stays the default; nothing snaps without the hold.
